# **App Name**: Swastik Sahayak

## Core Features:

- Product Showcase: Display available products with commission and selling price.
- Referral Link Generation: Enable sharing product links to social media and WhatsApp, but anyone who wants to view product need to register as reseller
- Reseller Onboarding: Implement user registration with fields for PAN, Aadhaar, and address proof, including file uploads.
- Product Upload: Product upload page has product dimension , weight , & image
- Product Description Generation: AI tool that provides similar Amazon product descriptions. Based on the admin-provided title and bullet points, automatically fill in the long-form product description.
- Detailed Product Pages: Display product details following Amazon standards (title, bullet points, description, specs, images, FAQs), including shipping dimensions.
- Contact and Support: Display Contact Us page with Google Map and inquiry form.
- Automated notifications: Inform the resellers on various milestones using Email/SMS notifications.
- Database Creation & Seeding: Automatically add firestore as database & please seed some demo data in database to crreate default table with new database name as swastiksahayak

## Style Guidelines:

- Primary color: Saffron (#FF7F50), inspired by traditional Indian handicrafts, giving a warm and inviting feel.
- Background color: Light beige (#F5F5DC), offering a neutral and clean backdrop.
- Accent color: Teal (#008080), for interactive elements, providing contrast and a modern touch.
- Font pairing: 'Playfair' (serif) for headings to convey elegance, and 'PT Sans' (sans-serif) for body text for readability.
- Use of handcrafted-style icons to complement the theme.
- Clean and modern layout, optimized for mobile responsiveness.
